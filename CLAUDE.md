# CLAUDE.md - Authenticator Extension Developer Guide

## 📋 Overview

**Authenticator** is a Chrome/Firefox browser extension that generates 2-Step Verification (2FA) codes locally in your browser. This guide explains the codebase structure, development workflows, and conventions for AI assistants working on this project.

**Repository**: [Authenticator-Extension/Authenticator](https://github.com/Authenticator-Extension/Authenticator)  
**License**: MIT  
**Language**: TypeScript  
**Target Browsers**: Chrome, Firefox

## 📦 Data Models

### **OTP Type Enum**
```typescript
enum OTPType {
  totp = 1,    // Time-based (Google Authenticator standard)
  hotp,        // Counter-based
  battle,      // Battle.net
  steam,       // Steam
  hex,         // Hex variant
  hhex         // HOTP Hex
}
```

### **OTPEntry Class** (src/models/otp.ts)
```typescript
class OTPEntry implements OTP {
  type: OTPType
  issuer: string       // e.g., "Google"
  account: string      // e.g., "user@gmail.com"
  secret: string       // Base32 encoded secret key
  code: string         // Current 6-digit code (e.g., "123456")
  counter: number      // For HOTP counter
  hash: string         // MD5 hash of secret
  index: number        // Position in list
  
  generate()           // Generate new code
  create(encryption)   // Save to storage
  update(encryption)   // Update in storage
  delete()            // Remove from storage
  next(encryption)    // HOTP: increment counter
}
```

### **Storage Format** (Chrome LocalStorage)
```json
{
  "accounts": {
    "hash1": {
      "issuer": "Google",
      "account": "user@gmail.com",
      "secret": "JBSWY3DPEBLW64TMMQ...",
      "type": "totp",
      "encrypted": false,
      "counter": 0
    }
  },
  "darkMode": "true",
  "zoom": "100",
  "offset": "0"
}
```

## 🔐 Security Considerations

### **Encryption**
- Secrets are encrypted at rest using AES-256 (optional via passphrase)
- Encryption key derived from user's passphrase using PBKDF2
- **File**: src/models/encryption.ts

### **Sensitive Data**
- Secrets stored in `chrome.storage.local` (not synced to cloud)
- Optional Dropbox backup with user consent
- Passphrase warning when secrets in plain localStorage

### **No Network Calls**
- Code generation happens locally
- Only Dropbox integration makes external requests
- Google clock sync for time offset (optional)

## 📝 Code Conventions

### **TypeScript Style**
- **Linter**: Google TypeScript Style (gts)
- **Indentation**: 2 spaces
- **Line Endings**: LF (Unix style)
- **Strict Mode**: Enabled (`"strict": true` in tsconfig.json)

### **Naming Conventions**
- **Classes**: PascalCase (e.g., `OTPEntry`, `Encryption`)
- **Functions**: camelCase (e.g., `generateCode()`, `updateStorage()`)
- **Constants**: UPPER_SNAKE_CASE (e.g., `MAX_CODE_LENGTH`)
- **Private fields**: Prefix with underscore (e.g., `_privateField`)

### **Module Pattern**
- No ES6 modules (due to CSP)
- Use TypeScript triple-slash references: `/// <reference path="..." />`
- Each module exports a single async function: `async function moduleName(_ui: UI)`

### **Vue.js v1.0 Notes**
- Direct HTML data binding: `{{ variable }}`
- Event handlers: `v-on:click="methodName()"`
- Conditionals: `v-show`, `v-if`
- Lists: `v-for="item in array"`
- Two-way binding: `v-model="property"`

## 🚀 Development Workflow

### **For AI Assistants**

#### **1. When Adding New Features**
1. **Modify TypeScript** in `src/`:
   - Add logic to appropriate model/ui file
   - Follow existing naming conventions
   - Use strict TypeScript types

2. **Update HTML** if UI changes in `view/popup.html`:
   - Use Vue.js directives
   - Reference new i18n strings

3. **Add Styles** in `css/popup.css`:
   - Follow existing color scheme
   - Add dark mode support (use `body.dark-mode` selector)
   - Test both light and dark modes

4. **Compile & Test**:
   ```bash
   npm run compile    # Check for TS errors
   npm run check      # Lint
   npm run chrome     # Build
   # Load in Chrome and test manually
   ```

5. **Commit**:
   ```bash
   git add -A
   git commit -m "Feature: description of changes
   
   - Bullet point 1
   - Bullet point 2
   
   https://claude.ai/code/session_ID"
   ```

#### **2. When Fixing Bugs**
1. Locate bug in `src/` based on error message
2. Add guards/checks (see type errors fix in test.ts)
3. Compile, check, build, test
4. Commit with "Fix:" prefix

#### **3. When Updating Translations**
1. Edit `_locales/en/messages.json`
2. Add `message` and `description` fields
3. Update other language files (or request via Crowdin)
4. Test with `{{ i18n.newKey }}`

#### **4. When Modifying UI Components**
1. **Light Mode**: Edit `css/popup.css` styles
2. **Dark Mode**: Add corresponding `body.dark-mode .selector` rules
3. **Vue Logic**: Edit corresponding `src/ui/*.ts` file
4. **HTML**: Update `view/popup.html` with Vue directives

## ⚠️ Important Rules

### **DO NOT**
- ❌ Use ES6 modules (no `import/export`)
- ❌ Modify compiled `/build/` or `/chrome/` directories directly
- ❌ Store secrets in plain text (use encryption)
- ❌ Make unnecessary network requests
- ❌ Use outdated TypeScript (2.6.1 minimum)
- ❌ Break multi-language support

### **DO**
- ✅ Always compile before testing: `npm run compile`
- ✅ Run linter before committing: `npm run check`
- ✅ Update i18n strings for all new UI text
- ✅ Test both light and dark modes
- ✅ Add TypeScript type annotations
- ✅ Use Vue.js v1.0 patterns (no Composition API)
- ✅ Keep security/encryption code reviewed

## 📖 Example: Adding a Feature

### **Scenario: Add "Copy Button" Feature**

#### 1. **HTML** (view/popup.html)
```html
<div class="code" v-on:click="copyCode(entry)">
  {{ entry.code }}
</div>
```

#### 2. **TypeScript** (src/ui/menu.ts)
```typescript
copyCode: (entry: OTPEntry) => {
  if (entry.code && entry.code !== '&bull;&bull;&bull;&bull;&bull;&bull;') {
    const clipboard = document.getElementById('codeClipboard') as HTMLInputElement;
    if (clipboard) {
      clipboard.value = entry.code;
      clipboard.select();
      document.execCommand('copy');
      _ui.instance.showNotification('Code copied!');
    }
  }
}
```

#### 3. **CSS** (css/popup.css)
```css
.code {
  cursor: pointer;
  transition: color 0.2s;
}

.code:hover {
  color: #0066FF;
}

body.dark-mode .code {
  color: #4FC3F7;
}
```

#### 4. **Translation** (_locales/en/messages.json)
```json
{
  "codeCopied": {
    "message": "Code copied!",
    "description": "Notification when code is copied to clipboard"
  }
}
```

#### 5. **Compile & Test**
```bash
npm run chrome
# Load in Chrome, test the feature
```
